## OpenAI / ChatGPT

- Memory FAQ: https://help.openai.com/en/articles/8590148-memory-daq
  - Current Memory summary model; Settings -> Personalization -> Memory; Temporary Chats do not use/create memories while temporary.
- Data Controls FAQ: https://help.openai.com/en/articles/7730893-data-controls-faq
  - Personal-account model-improvement control and Temporary Chat behaviour.
- Projects in ChatGPT: https://help.openai.com/en/articles/10169521-using-projects-in-chatgpt
  - Current file limits: Free 5/project; Go/Plus 25; Edu/Pro/Business/Enterprise 40. Limits/availability can change.
- GPTs in ChatGPT: https://help.openai.com/en/articles/8554407
  - OpenAI currently says custom GPTs are planned for retirement and recommends moving workflows to Plugins; dates/rollout can change.
- Plugin / app administration guidance: https://help.openai.com/en/articles/11509118
  - Workspace controls and data implications; provider verification is not a substitute for school/vendor review.

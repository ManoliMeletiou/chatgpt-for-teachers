# Offline / Live-room Failure Fallback

The workshop must survive without QR, relay or Wi-Fi.

## If phones cannot join

- Keep presenting in solo mode/projector mode.
- Participants use paper/notes for booklet prompts.
- Show the six-character code only if slide following works; do not improvise by collecting names/booklets through WhatsApp or personal email.

## If the presenter app fails

- Use the UI guide images under `product/source/public/slides/ui-guides/` for product-navigation sections.
- Use `TEACHER-QUICKSTART.md` for safety + SCOPE-V.
- Run the workshop as demonstration + paired practice.

## If ChatGPT itself is unavailable

Run three paper exercises:

1. Rewrite a vague prompt into SCOPE-V.
2. Classify six use cases Green/Amber/Red.
3. Red-team a prewritten AI output: find unsupported claims, bias, curriculum mismatch and missing verification.

The learning objective is teacher judgement, not service uptime.

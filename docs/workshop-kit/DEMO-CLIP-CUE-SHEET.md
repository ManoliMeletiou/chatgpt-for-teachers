# Demonstration / Micro-clip Cue Sheet

Do not rely on long generic YouTube videos. A workshop is stronger when each feature has a **30-90 second proof** recorded or demonstrated from the exact account/workspace being taught.

## Recommended micro-clips

1. **Data Controls - 30s:** open Settings -> Data Controls -> show “Improve the model for everyone”; explain what it changes and what it does not.
2. **Memory - 45s:** Settings -> Personalization -> Memory -> Memory summary/Manage; explain Temporary Chat difference.
3. **Project - 60s:** create one unit Project, add stable instructions, add one approved non-personal reference file.
4. **SCOPE-V - 60s:** paste bad prompt, improve it, compare output.
5. **Verification - 60s:** ask for sources/uncertainty, then independently check one claim.
6. **Writing block/document - 45s:** ask for a finished teacher artefact, open/edit the writing surface, run QA.
7. **Plugin/app permission - 45s:** open a plugin/app card and point to data/permission implications before connecting.
8. **Study Mode - 45s:** show a student-facing *teaching* prompt on synthetic/public content; reinforce that school policy still governs student use.

## Production rules

- Record the week of the workshop when possible.
- Crop to the relevant UI; hide account email, school files and notifications.
- Add a visible red circle/pointer at the click.
- No clip longer than 90 seconds.
- Caption every clip.
- Keep the UI guide image as a fallback if the live interface has moved.
- Never record with real student data visible.
